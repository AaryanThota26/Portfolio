# Interactive Terminal Portfolio Plan

## Goal
Create an interactive, terminal-themed portfolio that features standard sections (Projects, Experience, Skills, Contact) and fun interactive elements.

## Strategy
- **Framework:** HTML/CSS (single file) with vanilla JS for the terminal simulation.
- **Visuals:** Dark mode (black background, green/amber monospace font).
- **Features:** 
    - Auto-typing terminal intro.
    - Command prompt (e.g., `guest@portfolio:~$ `).
    - Commands: `help`, `about`, `projects`, `skills`, `clear`, etc.
    - Mini interactive game/Easter egg.
- **Deployment:** Single file artifact (no hosting needed).

## Steps
1. Draft the basic HTML skeleton.
2. Implement CSS for terminal styling.
3. Write JS for command simulation/handling.
4. Integrate Grid.js for the projects list table.
5. Final review and polishing.
